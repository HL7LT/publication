HL7 EU Imaging profiles

IM Composition

Clinical document used to represent a Imaging Study Report for the scope of the HL7 Europe project.

Diagnostic Report profile for Imaging Reports. This document represents the report of an imaging study. It is the anchor resource that refers to all structured data as well as the Composition resource that contains the narrative text of the report.
IM Document DiagnosticReport Reference

This extension provides a reference to the DiagnosticReport instance that is associated with this Composition.

Finding during imaging procedure.

This profile defines a placeholder for an Endpoint for a viewer that can be used to access the study, serie it is present on. The application is based on IHE-IID.

This profile on Identifier represents the Accession Number for the Imaging Order.

The device the made the image.

This profile on ServiceRequest represents the order for the Imaging Study and report.
IM Imaging Procedure

This profile on Procedure represents the imaging procedure.
IM Imaging Selection

Imaging Selection
IM Imaging Study

This profile represents an imaging study instance.
IM Instance Description

A description of the instance in an ImagingStudy.
IM Key Image Document Reference

A document containing key images for a patient. It can refer to a DICOM or non-DICOM image. When referring to a DICOM image, the DocumentReference.content.attachment.url should be a WADO-URI. When referring to a non-DICOM image, the DocumentReference.content.attachment.url should be a direct URL to the image.

When the resource represents a DICOM instance it SHALL contain a the SOP Instance UID in the identifier element. When the resource represents a DICOM series it SHALL contain the Series Instance UID in the identifier element.

EU Lab profiles

EU Lab profiles

Composition: Laboratory Report (Eu Lab)

Clinical document used to represent a Laboratory Report for the scope of the HL7 Europe project.
DiagnosticReport: Laboratory Report (Eu Lab)

DiagnosticReport used to represent an entry of a Laboratory Report, including its context, for the scope of the HL7 Europe project.
Extension: Document DiagnosticReport Reference (Eu Lab)

This extension provides a reference to the DiagnosticReport instance that is associated with this Composition.
Extension: Specimen Container Type

Type of container used for the specimen.
Observation Results: laboratory (Eu Lab)

This profile constrains the Observation resource to represent results produced by laboratory tests or panels/studies for the HL7 Europe project. This observation may represent the result of a simple laboratory test such as hematocrit or it may group the set of results produced by a multi-test study or panel such as a complete blood count, a dynamic function test, a urine specimen study. In the latter case, the observation carries the overall conclusion of the study and or a global interpretation by the producer of the study, in the comment element; and references the atomic results of the study as "has-member" child observations.
ServiceRequest: Laboratory Order (Eu Lab)

This profile defines how to represent an laboratory orders using the HL7 FHIR ServiceRequest for the purpose of this guide.
Specimen: Laboratory (Eu Lab)

This profile defines how to represent Specimens in HL7 FHIR for the purpose of this guide.
Substance: Specimen Additive Substance (Eu Lab)

This profile defines how to represent Specimen Additive Substances in HL7 FHIR for the purpose of this guide.
