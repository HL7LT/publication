Data Type Profile: Quantity (Eu Lab)

Official URL: http://hl7.eu/fhir/laboratory/StructureDefinition/Quantity-eu-lab Version: 0.0.1
Computable Name: QuantityEuLab

Copyright/Legal: Used by permission of HL7 Europe, all rights reserved Creative Commons License

This profile constrains the Quantity data type to use UCUM as the code system for units and optionally share measurement uncertainty

Usages:

  • Use this DataType Profile: Observation Results: laboratory (Eu Lab)

You can also check for usages in the FHIR IG Statistics
