Duomenų tipo profilis: Codeable Concept (IPS)

Oficialus URL: http://hl7.org/fhir/uv/ips/StructureDefinition/CodeableConcept-uv-ips Versija: 2.0.0
Mašiniškai apdorojamas pavadinimas: CodeableConceptIPS

This profile represents the constraint applied to the CodeableConcept data type by the International Patient Summary (IPS) FHIR Implementation Guide to use the Coding-uv-ips data type profile.

Usages:

  • Use this DataType Profile: Composition: Laboratory Report (Eu Lab), DiagnosticReport: Laboratory Report (Eu Lab) and Observation Results: laboratory (Eu Lab)

You can also check for usages in the FHIR IG Statistics
