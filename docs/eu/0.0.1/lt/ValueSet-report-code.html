ValueSet: Report Code

Oficialus URL: https://hl7.lt/fhir/eu/ValueSet/report-code Versija: 1.0.0
Mašiniškai apdorojamas pavadinimas: ReportCode

Diagnostic report codes including all subtypes of Clinical procedure report, excluding the root concept itself.

References

This value set is not used here; it may be used elsewhere (e.g. specifications and/or implementations that use this content)

Language: en
