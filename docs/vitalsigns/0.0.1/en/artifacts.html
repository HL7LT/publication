Structures: Resource Profiles

These define constraints on FHIR resources for systems conforming to this implementation guide.

Blood Pressure Panel

Blood Pressure Panel; a grouping of systolic, diastolic, and mean arterial blood pressure components.
Body Height

The measurement in centimeters or feet and inches from the top of the head to the heel, usually while standing.
Body Mass Index

Body Mass Index (BMI) is a measure of body fat based on height and weight.
Body Structure for Blood Pressure

Body Structure profile to describe where on the body a blood pressure measurement was taken.
Body Weight

The measured mass of an individual's body.
Body Weight Measurement Device

Device used to measure body weight.
Device for Blood Pressure Measurement

Device used to measure blood pressure.
Device for Body Height Measurement

Device used to measure body height.
Device for Heart Rate Measurement

Device used to measure heart rate.
Head Circumference

Head Occipital-frontal circumference by Tape measure. The measurement in centimeters or inches around the largest part of the head.
Heart Rate

The number of heart beats in a minute.
Waist Circumference

Waist circumference by Tape measure. The measurement in centimeters or inches around the narrowest part of the waist.

Structures: Extension Definitions

These define constraints on FHIR data types for systems conforming to this implementation guide.

Associated Situation Extension

Situations that may affect the measurement or assessment.
Body Position Extension

The position of the body when the observation was done, e.g. standing, sitting. To be used only when the body position in not precoordinated in the observation code.
Exercise Association Extension

The exercise state associated with the measurement.
Measurement Setting Extension

The location or setting the subject was in when the measurement was obtained. For example, home, clinic, hospital. etc.
Sleep Status Extension

The state of wakefulness during the measurement.

Terminology: Value Sets

These define sets of codes used by systems conforming to this implementation guide.

BMI Units

UCUM units for recording BMI
BP Diastolic observation codes

This value set defines the set of LOINC codes considered to be appropriate for representing an arterial diastolic BP vital sign measurement in Observation.component.code.
BP Panel observation codes

This value set defines the set of LOINC codes considered to be appropriate for representing an arterial szstolic and diastolic BP panel of vital signs measurements in Observation.component.code.
BP Systolic observation codes

This value set defines the set of LOINC codes considered to be appropriate for representing an arterial systolic BP vital sign measurement in Observation.component.code.
Blood Pressure Cuff Size

SELECT SNOMED CT code system values that describe the size of blood pressure cuff in use.
Blood Pressure Measurement Body Location

SELECT SNOMED CT code system values that describe the location on the body where the blood pressure was measured.
Blood Pressure Measurement Method

SELECT SNOMED CT code system values that describe how a blood pressure was measured.
Blood Pressure Units

UCUM units for recording blood pressure.
Body Height observation codes

This value set defines the set of LOINC codes considered to be appropriate for representing body height (including body length) vital sign measurements in Observation.code.
Body Length Units

UCUM units for recording body length measures such as height and head circumference
Body Position used in Vital Signs Measurements

SELECT SNOMED CT code system values the position in which the individual was in during a measurement.
Body Weight Associated Situation

SELECT SNOMED CT code system values and temporary code system values that describe situations to be considered when interpreting measured values.
Body Weight observation codes

This value set defines the set of LOINC codes considered to be appropriate for representing body weight vital sign measurements in Observation.code.
Device Types for Blood Pressure Measurement

SELECT SNOMED CT code system values that describe the isntrument used to measure the blood pressure.
Device Types for Heart Rate Measurement

SELECT SNOMED CT code system values that describe the instrument used to measure the heart rate.
Device Types for Height Length Measurement

SELECT SNOMED CT code system values that describe the instrument used to measure the body height/length.
Device Types for Weight Measurement

SELECT SNOMED CT code system values that describe the instrument used to measure the body weight.
Exertion Phase

SELECT SNOMED CT code system values that contains terms for exercise associated with a measurement.
Heart Rate Measurement Body Location

SELECT SNOMED CT code system values that describe where on the body the heart rate was measured.
Heart Rate Measurement Method

SELECT SNOMED CT code system values that describe how the heart rate was measured.
Heart Rate observation codes

This value set defines the set of LOINC codes considered to be appropriate for representing heart rate vital sign measurements in Observation.code.
Height Length Measurement Method

SELECT SNOMED CT code system values that describe how the height/length was measured.
Measurement Environment

Environment that indicate the surroundings the individual was in during the measurement (i.e. home, clinic, hospital, etc.).
Numeric Result Interpretation value set

The HL7 V3:ObservationInterpretation code set (OID: 2.16.840.1.113883.5.83) that describes interpretations associated with a measured value.
Numeric Result Interpretation without panic values, value set

The HL7 V3:ObservationInterpretation code set (OID: 2.16.840.1.113883.5.83) that describes interpretations associated with a measured value, constrained to terms that are not those associated with 'panic' terms.
Rate Units

UCUM rate units for recording vital signs including heart and respiratory rate.
Sleep Status in Vital Signs Measurements

SELECT SNOMED CT code system values that contains terms used to indicate the state of wakefulness during measurement.
Waist Circumference observation codes

Waist circumference observations.

Terminology: Code Systems

These define new code systems used by systems conforming to this implementation guide.

SNOMED CT Solor Extension Temporary Code System

A set of codes that are defined in the Solor extension to the SNOMED CT code system. To be used until they are adopted by SNOMED CT.
