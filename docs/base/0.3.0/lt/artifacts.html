Šiame puslapyje pateikiamas FHIR artefaktų, apibrėžtų šiame diegimo vadove, sąrašas.

Struktūros: Resursų profiliai

Jie apibrėžia FHIR resursų apribojimus sistemoms, atitinkančioms šį įgyvendinimo vadovą.

AppointmentLt

Lithuanian Base Appointment profile, used for planing visit to healthcare services.
CarePlanLt

Lithuanian Base CarePlan profile, used for describing care plans.
CareTeamLt

Lithuanian Base Care Team profile, used for documenting care teams involved in patient care.
CompositionLt

Lithuanian Base Composition profile, used for creating healthcare compositions.
ConditionLt

Lithuanian Base Condition profile, used for documenting general, symptoms, conditions, and their characteristics.
DiagnosticReportLt

Lithuanian Base DiagnosticReport profile, used for interpretation of diagnostic tests.
DocumentReferenceLt

Lithuanian Base Document Reference profile, used for composing documents.
EncounterLt

Lithuanian Base Encounter profile, used to represent clinical encounters
EpisodeOfCareLt

Lithuanian Base EpisodeOfCare profile, used for composing episodes of care.
FamilyMemberHistoryLt

Lithuanian Base FamilyMemberHistory profile, used for health conditions for a person related to the patient.
GoalLt

Lithuanian Base Goal profile, used for describing goals.
HealthcareServiceLt

Lithuanian Base HealthcareService profile, used for describing provided healthcare services.
ImagingStudyLt

Lithuanian Base Imaging Study profile, used for documenting general imaging studies and their characteristics.
LocationLt

Lithuanian Base Location profile, used for documenting healthcare locations.
ObservationLt

Lithuanian Base Observation profile, used to represent vitals, demographic, clinical and laboratory observations
OrganizationLt

Lithuanian Base Organization profile, used to define healthcare organizations and sub-units
PatientLt

Lithuanian Base Patient profile, used to represent patients administrative information
PractitionerLt

Lithuanian Base Practitioner profile, used to define healthcare practitioners
PractitionerRoleLt

Lithuanian Base Practitioner Role profile, used to define roles of the healthcare practitioner in the healthcare facilities
ProcedureLt

Lithuanian Base Procedure profile, used for documenting healthcare procedures.
RelatedPersonLt

Lithuanian Base Related Person profile, used to define persons related to a patient
ServiceRequestLt

Lithuanian Base Service Request profile, used for documenting general, symptoms, conditions, and their characteristics.
